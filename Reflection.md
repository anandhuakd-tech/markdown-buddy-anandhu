## Reflection 1 – AI Support

ChatGPT helped me organize the documentation for my R project. It suggested common README sections such as Overview, Installation, Example Code, Results, and License. It also helped organize the R Markdown file into clear sections such as Purpose, Inputs, Processing, Outputs, and Verification. This made the documentation easier to structure and understand.

## Reflection 2 – Strengths and Limitations

One strength of using AI was that it quickly suggested clear Markdown structures and formatting. However, I learned that AI-generated content still needs to be checked manually. Code examples, calculations, filenames, and descriptions may not always match the actual project. I therefore compared the suggestions with my R script before using them.

## Reflection 3 – Verification and Ethical Use

I verified the documentation by comparing it with my R script and manually checking selected calculations. For example, I verified that the Laptop inventory value is 25 × $850 = $21,250 and that Keyboard is below its reorder level because its quantity is 8 while its reorder level is 15. I used only synthetic data and did not provide any real customer or personal information to the AI. I also disclosed my use of ChatGPT and documented the prompts used.
